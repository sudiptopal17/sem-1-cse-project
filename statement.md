# This is a game named rock paper and scissors

It is a simple turn based game where a user and computer based bot compette each  other, this game is quite efficient for an user to understand about core programming language which includes loop,condition, and randomization.It is named classicaly with the name rock paper and scissors.




# What's inside this game (the running part)

- This game start with a yes/no input where you type yes to start the game
- Takes users move as an text input (rock, paper, scissor)
- Generates a computer based choice in reutrn form the import random , using Pythons random module
- Compare both moves of the user as well as computer and the decides the winner using the conditional logic
- Tracks the score of the both player and computer for the final decision 
- Ends when player or the bot reaches 3 wins and declares the final winner
- The first to complete 3 point win the match
